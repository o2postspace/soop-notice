1. 처리하는 정보

이용자가 직접 보내는 정보

커뮤니티를 사용하면 게시글·댓글·추천·신고 내용과 작성 시각이 저장되며, 작성자가 입력한 삭제 비밀번호도 일방향 암호화해 저장합니다. 삭제 비밀번호 원문은 저장하지 않습니다.

건의·문의 기능을 사용하면 입력한 제목과 내용이 저장됩니다. 이름, 전화번호, 이메일 주소를 필수로 요구하지 않지만 이용자가 본문에 직접 적은 정보는 함께 처리될 수 있습니다. 이메일로 문의하면 메일 주소, 제목, 본문과 첨부 정보가 이메일 서비스에서 처리됩니다.

공개 공지와 방송에서 확인하는 정보

공개된 SOOP 채널의 채널 ID·닉네임·프로필 이미지, 공지 제목·본문·이미지·작성 시각·조회수·원문 주소와 이를 바탕으로 정리한 방송 예정 시각·라이브 상태를 처리합니다.

후국지 현황은 비밀번호 없이 볼 수 있는 공개 방송 화면에서 확인되는 참가자 식별 정보, 진영·직업, 능력치, 장비·말·스킬 강화 수치, 관측 시각과 출처를 처리하며 이를 바탕으로 현황표와 파워랭킹을 계산합니다. 원본 방송의 음성은 저장하지 않습니다.

서비스 이용 과정에서 자동 처리될 수 있는 정보

호스팅, 보안과 도배 방지 과정에서 IP 주소, 브라우저와 기기 정보, 접속 시각, 방문 페이지, 쿠키 또는 임의 식별자가 자동으로 처리될 수 있습니다. 커뮤니티 데이터베이스에는 원본 IP 주소 대신 비밀키로 변환한 단기 식별값을 사용합니다. 공개 화면의 익명 표시는 IP 주소를 노출하지 않습니다.

주민등록번호, 결제 정보, 실명은 요구하지 않습니다. 게시글이나 댓글에 자신의 개인정보 또는 타인의 개인정보를 입력하지 마세요.

2. 이용 목적과 보유 기간

공개 공지·일정공지 탐색, 방송 일정 정리와 원문 연결에 사용합니다. 서비스 제공에 필요한 동안 보관하며, 원문이 비공개·삭제되었거나 권리자의 정정·삭제 요청이 확인된 경우 표시 수정 또는 삭제를 검토합니다.
후국지 관측값·파생 순위참가자 현황과 관측 근거를 확인하고 파워랭킹을 계산하는 데 사용합니다. 해당 이벤트 운영과 검증에 필요한 동안 보관하며, 당사자나 권리자의 정정·삭제·관측 제외 요청이 확인된 경우 수정 또는 제외를 검토합니다.
임시 방송 화면공개 방송에서 게임 정보 화면을 판별하고 누락된 값을 재확인하는 데 사용합니다. 화면 이미지만 접근이 제한된 내부 저장소에 임시 보관하며 음성은 저장하지 않습니다. 일반 후보 화면은 기본 30분 뒤 정리하고 재처리가 필요한 경우에도 생성 후 최대 24시간 안에 삭제합니다.
커뮤니티 내용게시글·댓글 표시, 추천과 신고 처리에 사용합니다. 이용자 또는 운영자가 삭제할 때까지 보관하며, 삭제된 내용은 공개 화면에서 즉시 숨깁니다.
익명 브라우저 식별자같은 글 안의 익명 이름 구분, 작성자 확인과 중복 추천 방지에 사용하며 최대 1년 또는 이용자가 사이트 데이터를 삭제할 때까지 유지합니다.
글별 가명 식별값같은 글 안의 작성자 구분과 추천·신고 중복 방지에 사용합니다. 서로 다른 게시글의 활동을 연결할 수 없도록 대상별로 다르게 생성하며, 해당 게시글·댓글·추천 또는 신고 기록의 보유 기간 동안 함께 보관합니다.
부정 이용 식별값도배, 중복 추천, 반복 신고와 공격을 막기 위해 사용합니다. 원본 IP를 커뮤니티 데이터베이스에 저장하지 않고 단기 변환값을 사용하며, 마지막 활동 후 7일 이내 삭제합니다.
건의·문의 내용오류 확인, 답변과 기능 개선에 사용합니다. 처리 목적이 끝나면 삭제하며 운영 기록이 필요한 경우에도 목적에 필요한 기간만 보관합니다.
접속·보안 기록서비스 안정성 확인, 장애 대응과 비정상 요청 차단을 위해 호스팅·보안 제공자의 정책에 따라 처리될 수 있습니다.
통계 정보방문 규모, 자주 사용하는 화면, 오류 발생 여부를 집계해 사용성과 성능을 개선하는 데 사용합니다.

법령에 따라 보존할 의무가 있거나 분쟁 대응에 필요한 경우에는 해당 목적과 기간에 한해 보관할 수 있습니다.

3. 브라우저 저장 정보

숲공지는 개인 설정과 최근 후국지 현황의 빠른 표시를 위해 브라우저의 localStorage를 사용합니다.

  • 본진 목록: 이용자가 선택한 관심 스트리머 ID. 이용자가 브라우저의 사이트 데이터를 삭제할 때까지 유지됩니다.
  • 화면 설정: 다크모드 사용 여부. 이용자가 브라우저의 사이트 데이터를 삭제할 때까지 유지됩니다.
  • 후국지 화면 캐시: 최근 현황 응답과 저장 시각. 저장 후 최대 24시간까지만 사용하며 그 이후에는 새 데이터를 요청합니다.

이 정보는 기본적으로 이용자의 기기 안에만 저장되며 숲공지 서버로 전송해 계정과 결합하지 않습니다. 브라우저 설정에서 사이트 데이터를 삭제하면 초기화할 수 있습니다.

비회원 익명 구분에는 브라우저 JavaScript에서 읽을 수 없는 보안 쿠키를 사용하며 최대 1년 동안 유지됩니다. 브라우저의 사이트 데이터 삭제로 즉시 제거할 수 있습니다. 쿠키를 삭제해도 작성 당시 설정한 삭제 비밀번호로 자신의 글과 댓글을 삭제할 수 있습니다.

4. 쿠키와 외부 서비스

숲공지는 아래 외부 서비스를 기능 제공에 필요한 범위에서 사용합니다. 각 제공자는 요청 처리 과정에서 IP 주소, 기기·브라우저 정보 또는 전송된 공개 데이터를 처리할 수 있으며, 제공자의 글로벌 인프라에서 국외 처리가 이루어질 수 있습니다.

Cloudflare

정적 페이지 제공, 도메인 연결, 보안과 쿠키를 사용하지 않는 방문 통계 확인에 사용합니다. Cloudflare는 요청 전달과 공격 차단 과정에서 접속 정보를 처리할 수 있습니다. 자세한 내용은 Cloudflare Privacy Policy를 확인하세요.

Google Gemini

공개 공지에서 방송 날짜와 시작 시각을 정리하기 위해 공지 제목·본문과 공지에 포함된 공개 이미지를 Google Gemini에 전송할 수 있습니다. 후국지 임시 방송 화면은 이 일정 추출 용도로 Gemini에 전송하지 않습니다. Google의 처리 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

Google Sheets

후국지 참가자의 공개 식별 정보, 관측된 게임 수치, 관측 시각과 출처를 운영용 표와 공개 현황에 동기화하는 데 사용합니다. Google의 처리 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

SOOP 및 원본 이미지 제공자

공지 원문, 방송 페이지, 프로필과 공지 이미지를 표시할 때 이용자의 브라우저가 SOOP 또는 해당 원본 이미지 호스트로 직접 요청할 수 있습니다. 이때 해당 제공자가 IP 주소, 브라우저 정보와 요청 시각을 처리할 수 있으며 각 제공자의 정책이 적용됩니다.

이메일 서비스

이용자가 이메일로 문의하면 이메일 주소, 제목, 본문과 첨부 정보가 메일 전송과 답변을 위해 이메일 제공자의 시스템에서 처리됩니다.

5. 제3자 제공과 처리 위탁

숲공지 운영자는 서비스 데이터나 이용자가 문의에 적은 개인정보를 광고 목적으로 이용하거나 판매·제공하지 않습니다. 다만 위에 적은 호스팅, 보안, 분석, 데이터 관리와 이메일 서비스가 기능 제공에 필요한 범위에서 정보를 처리할 수 있습니다. 법령에 따른 요청이 있거나 생명·안전 보호를 위해 필요한 예외 상황에서는 관련 법령이 허용하는 범위에서 제공될 수 있습니다.

6. 이용자의 권리와 행사 방법

작성자는 작성 당시 설정한 삭제 비밀번호로 자신의 게시글·댓글을 삭제할 수 있습니다. 건의·문의 정보의 열람, 정정, 삭제, 처리 중지는 이메일로 요청할 수 있습니다.

공지 작성자, 방송 당사자 또는 권리자는 공개 공지·일정·후국지 관측값의 정정, 표시 중지, 삭제 또는 이후 관측·랭킹 제외를 요청할 수 있습니다. 요청했다는 이유로 서비스 이용에 불이익을 주지 않습니다.

요청 시 해당 내용을 찾을 수 있도록 원문 주소, 스트리머명 또는 참가자명, 대략적인 관측 시각과 요청 사유를 알려주세요. 타인의 정보를 보호하기 위해 필요한 경우 요청자 확인이나 권리 관계 확인에 필요한 최소 정보만 요구할 수 있습니다.

브라우저에 저장된 본진 목록과 다크모드 정보는 이용자가 브라우저의 사이트 데이터 삭제 기능으로 직접 제거할 수 있습니다.

7. 안전성 확보 조치

사이트는 HTTPS 통신을 사용하고 삭제 비밀번호를 느린 일방향 해시로 보호합니다. 데이터베이스 접근 권한을 운영에 필요한 범위로 제한하고 외부 입력에는 길이·형식 검증과 매개변수화된 쿼리를 적용합니다. 비밀키와 관리용 인증 정보는 공개 페이지에 포함하지 않습니다.
